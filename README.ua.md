# Калькулятор Палет

[English Version](README.md)

Веб-додаток для розрахунків для цеху розливу. Цей додаток може підійти не для всіх, адже процеси можуть відрізнятися на різних підприємствах.

## Можливості

- **Розрахунок кількості**: Підрахунок повних палет, залишку пляшок та кількості рядів (шарів) на неповному палеті.
- **Розрахунок за часом**: Обчислення потрібної кількості палет до цільового часу та тривалості запасу.
- **Час рядів та секундомір**: Замір часу обробки 1 ряду та розрахунок часу на палету.
- **База палет**: Збереження, редагування та пошук продукції (пляшки, ряди, час, зона, примітки). Миттєвий вибір палети з бази в калькулятор.
- **Аналітика**: Загальні показники кількості палет, пляшок, рядів та статистика використання.
- **Локальні дані**: Збереження на пристрої з можливістю експорту та імпорту в JSON.
- **PWA**: Нижня панель навігації, адаптивний дизайн та підтримка офлайн-режиму.

## Технології

- React 19, TypeScript
- Vite 6
- Vanilla CSS

## Розробка та запуск

```bash

npm install

# Запуск локального сервера
npm run dev

# Збірка проекту
npm run build

# Перевірка коду

```
